# calculator-odin-project
Calculator project
In this project from The Odin Project, you will build a fully functional on-screen calculator using HTML, CSS, and JavaScript. The assignment challenges you to create your own core mathematical functions (add, subtract, multiply, and divide) and wire them to a user interface with functional digit and operator buttons. To complete the project, you must write the logic to store user inputs and evaluate mathematical expressions dynamically, all while avoiding built-in but potentially dangerous shortcuts like eval().
